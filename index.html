ArcGIS Ski Map

An interactive ArcGIS Online application demonstrating spatial analysis and web mapping techniques.

View Web App

Project Development Notes

This project builds on an initial map of ski resorts in Massachusetts by improving both the design and interactivity. The basemap layers were made consistent for a more uniform look, and the ski resort symbols were updated with a clearer mountain icon so they stand out more.

Major roads were added to help show transportation routes and improve understanding of accessibility to each ski resort. An elevation layer was also included to visualize terrain differences across the state and provide more geographic context.

The map was also turned into a web app to increase interactivity. Users can toggle layers like roads and elevation on and off, and use a search tool to enter addresses and see how close they are to ski resorts.

Overall, the map has been improved from a basic visualization into a more interactive tool for exploring ski resort location, access, and terrain in Massachusetts.

Childhood Favorites in My Area

A personal geographic exploration highlighting meaningful childhood locations and community spaces.

Open Project

Project Development Notes

This project builds on an initial map of childhood favorite locations by adding more points of interest and improving interactivity. Three categories—Parks, Food, and Fun—were added so locations can be explored in an organized way. Each point includes clickable popups with basic descriptions.

A simple control panel with checkboxes was added so users can turn categories on and off depending on what they want to see. A zoom feature was also included so users can click on a location and zoom in for more detail. The title and controls were adjusted to improve readability and layout.

This map is mainly a personal project, meant to share my own experiences and memories from different places. While it is not designed for a broad audience, it could still be useful for friends or family in the area to find nearby parks, restaurants, or activity spots, or for simple educational use in showing local places.

Massachusetts Coast: Navigation and Infrastructure

A coastal mapping project focused on navigation systems, infrastructure, and spatial relationships along the Massachusetts shoreline.

Open Project

Project Development Notes

This project builds upon an initial map of Massachusetts lighthouses by incorporating additional layers and significantly enhancing interactivity and user experience. Two new datasets—seaports and ferry traffic routes—were added to provide a more comprehensive view of coastal navigation and infrastructure.

Each layer includes interactive features such as clickable elements, allowing users to explore detailed information dynamically.

To improve usability, a control panel with checkboxes was implemented using a toggle layer function, enabling users to turn layers on and off based on their interests. Visual clarity was also improved by removing lighthouse labels to reduce clutter, refining typography, updating the title, and adding a background for better readability.

Overall, the map has progressed from a single-layer visualization with basic interactivity to a multi-layer, user-controlled interface that enhances exploration, functionality, and user engagement. It is particularly useful for individuals traveling along the Massachusetts coast—such as ferry passengers—by helping them visualize routes, identify ports of departure and arrival, understand ferry operators, and anticipate nearby landmarks like lighthouses.
